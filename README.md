# АвтоРучка для Android

Android-версия десктопного приложения [АвтоРучка](https://github.com/androe123/AutoPen): генератор реалистичных рукописных конспектов на фотографиях тетрадных листов. Введите текст, выберите почерк и цвет чернил, загрузите фото страниц, подгоните границы и сетку — и сохраните результат в PDF или PNG.

## Скачать

Готовый APK — во вкладке **[Releases](../../releases/latest)** (или в артефактах последней сборки во вкладке **Actions**).
При установке Android попросит разрешить установку из неизвестных источников.

Требуется Android 8.0 и новее.
